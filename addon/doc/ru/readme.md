# UnicodeBrailleInput

* Авторы: Mesar Hameed, Patrick Zajda, Leonard de Ruijter.
* Загрузить [стабильную версию][1]

Это дополнение позволяет выполнять ряд задач по преобразованию текста в брайль.
Например, вы можете преобразовать текст из точечного обозначения брайля (например, 1345-1236-145-1) в брайлевские символы Unicode или ASCII.
Вы также можете преобразовать текст в соответствии с выбранной в данный момент таблицей Брайля для ввода или вывода, либо набрав или вставив его в поле ввода, либо импортировав текстовый файл.
Результат можно либо скопировать в буфер обмена, либо экспортировать в текстовый файл или файл формата BRF.

Первоначальная цель этого специализированного дополнения заключалась в том, чтобы упростить процесс улучшения таблиц liblouis и добавления автоматических тестов для вашего языка.
Однако с добавлением таблицы брайлевского шрифта Unicode в NVDA 2017.3 это дополнение больше не требуется.
Теперь пользователи могут выбрать ввод Брайля с помощью этой таблицы, либо с брайлевской клавиатуры, либо через [дополнение Ввода брайля с клавиатуры ПК][2].

## Пример использования

* Откройте текстовый редактор (например, Notepad plus plus).

* Нажмите NVDA+Ctrl+i или Выберите Ввод брайлевского юникода, который находится в меню инструментов NVDA.

* Введите брайлевский текст в цифровом виде или в обычном текстовом формате соответственно. При желании вы также можете импортировать текст из текстового файла.

* Выберите, будут ли вводимые данные содержать точки Брайля (например, 1345-1236-145-1) или обычный текст в соответствии с текущей таблицей Брайля (например, голландский (Нидерланды).

* Выберите тип вывода. Оставьте значение брайлевского Юникода или, при желании, измените на BRF или NABC.

* Выберите тип экспорта:
  * Если установить значение `Буфер обмена`, результат будет скопирован в буфер обмена, и вы сможете вставить его после нажатия кнопки ОК.
  * Если выбрать вариант `Файл`, после нажатия кнопки ОК появится окно сохранения.

## Изменения

### Изменения для 5.0

* Для работы дополнения теперь требуется NVDA 2024.3 или выше
* Заменены радиокнопки в комбинированных списках
* Добавлены типы вывода для брайля ASCII (BRF) и NABC (североамериканский компьютерный код Брайля с полным набором символов Latin1)

### Изменения для 4.1

* Для работы дополнения теперь требуется NVDA 2023.1 или выше
* Добавлена поддержка пользовательских брайлевских таблиц в качестве таблицы ввода

### Изменения для 4.0

* Дополнение совместимо с NVDA 2024.1
* Изменён жест для открытия диалога ввода брайлевского юникода с NVDA+control+u на NVDA+control+i

### Изменения для 3.4

* Дополнение совместимо с NVDA 2023.1

### Изменения для 3.3

* Дополнение совместимо с NVDA 2022.1

### Изменения для 3.2

* Дополнение совместимо с NVDA 2021.1
* Исправлена ошибка, вызывавшая трассировку стека при вводе неправильных данных в режиме точечного ввода. Теперь вместо этого отображается дружественное сообщение
* Обновлены переводы.

### Изменения для 3.1

* Порядок перехода по вкладкам для радиокнопок и элемента управления редактированием ввода был изменён.
* Обновлены переводы.

### Изменения для 3.0

* Новый сопровождающий: Leonard de Ruijter.
* Дополнение совместимо с Python 3 и, следовательно, с NVDA 2019.3 и выше.
* Добавлена возможность создавать шрифт Брайля в юникоде из обычного текста в соответствии с выбранной в данный момент брайлевской таблицы ввода.

### Изменения для 2.0

* Справка дополнения доступна в диспетчере дополнений.

### Изменения для 1.1

* Уменьшена задержка, чтобы позволить правильно услышать объявления.
* Многие новые переводы.
* Добавлено документация в меню справки NVDA.
* Добавлен флажок для необязательной замены пробела брайля (символ 0x2800) на регулярный символ пробела.
* Горячие клавиши теперь могут быть переназначены с помощью диалога ввода жестов NVDA в подкатегории Сервис.

### Изменения для 1.0

* Первоначальный выпуск
* Новый язык: французский
